**分組規則**
- 以「報名當學年度」年級為準，系統依年級自動分組，不可自選跨組。
- 性別拆組：該組別某一性別報名人數 > 20 人時，該組拆成「男子組」「女子組」各自排名、各取前 2 名。拆組後兩組 **使用相同路線**，只是分開排名。
- 拆組判定時間點：每場報名截止當天由系統統計後鎖定，並公告於網站。

## 3. 大亂鬥路線設計（第 1–3 場）

### 3.1 共線原則
- 每組 6–8 條路線。
- **相鄰組別共用 4 條路線**（前一組最難的 4 條 = 後一組最簡單的 4 條）。
- 中間組別（G2、G3、G4）同時與上、下組別共線，因此 **必須為 8 條**（下共線 4 + 上共線 4）。
- 頭尾組別（G1、G5）為 6–8 條（共線 4 + 專屬 2–4 條）。

### 3.2 路線梯度表（以每組 8 條為例，共 24 條）

路線依難度由易到難編號 R01–R24：

| 路線 | R01–R04 | R05–R08 | R09–R12 | R13–R16 | R17–R20 | R21–R24 |
|---|---|---|---|---|---|---|
| G1 1–3 年級 | ● | ● | | | | |
| G2 4–5 年級 | | ● | ● | | | |
| G3 小六國一 | | | ● | ● | | |
| G4 國二國三 | | | | ● | ● | |
| G5 高中 | | | | | ● | ● |

- 若場地牆面不足，G1、G5 可各減為 6 條 → 全場共 **20 條**。
- 明德、大埔場地大小不同，可依現場調整，但「中間組 8 條、相鄰共 4 條」的結構維持不變，系統後台以「路線 ↔ 組別」對應表設定即可。

### 3.3 路線分數
- 每條路線依難度給固定分數，**共線路線在兩個組別分數相同**（裁判端不用分辨選手組別，降低出錯）。
- 建議配分：R01 = 100 分，每往上一條 +50 分（R24 = 1250 分）。實際分數由定線員評定後於後台設定。
- 只判「完攀／未完攀」。（可選：增設 Zone 點，Zone 得該路線一半分數。）

### 3.4 計分與排名
1. **總分**：所有完攀路線分數加總（同一路線只計一次）。
2. 同分時比 **完攀條數** 多者勝。
3. 再同分比 **完攀所用總嘗試次數** 少者勝。
4. 再同分比 **達到最終分數的時間** 早者勝。
5. 仍同分則並列。

### 3.5 排隊與叫號規則
- 選手持號碼布／手環到該路線區的 **比賽 iPad 感應** → 選擇路線 → 取得排隊號碼。
- **同一時間只能排一條路線**；完成（或放棄）後才能再排下一條。
- 叫號螢幕顯示「上場」與「準備」兩位；叫號後 **60 秒** 未到視同棄權本次，需重新排隊。
- 每次上場即計一次嘗試；每次嘗試限時（建議 1–3 年級 3 分鐘、其他 4 分鐘）。
- 完攀後該路線不得再排（避免占用）。
- 裁判於手機點選「完攀／未完攀」後，系統自動叫下一位。

### 3.6 梯次安排（重點：共線組別錯開）
因只有「相鄰」組別共線，可把不相鄰組別排在同一梯次，**同梯次之間完全沒有共用路線**，不會搶隊伍：

- **A 梯次**：G1、G3、G5（使用全部路線）
- **B 梯次**：G2、G4（使用 R05–R20）

### 3.7 單場流程（上午比賽、下午練習）

| 時間 | 內容 |
|---|---|
| 07:45–08:30 | 報到、領號碼布／感應手環、簽同意書 |
| 08:30–08:45 | 開幕、規則說明、iPad 排隊示範 |
| 08:45–09:00 | A 梯次熱身 |
| 09:00–10:15 | **A 梯次比賽**（G1、G3、G5，75 分鐘） |
| 10:15–10:30 | 換場、B 梯次熱身 |
| 10:30–11:45 | **B 梯次比賽**（G2、G4，75 分鐘） |
| 11:45–12:15 | 成績確認、申訴受理（15 分鐘內） |
| 12:15–12:40 | **頒獎**（各組前 2 名） |
| 12:40–13:30 | 午餐休息 |
| 13:30–16:00 | **比賽練習**：比賽路線開放、教練分組指導（為下一場／正式賽做準備） |

> 容量估算：每次嘗試含換人約 3 分鐘 → 每條路線每梯次約 25 次嘗試。
> A 梯次 24 條 ≈ 600 次、B 梯次 16 條 ≈ 400 次；以每人 10–12 次嘗試估算，
> **A 梯次約 50–60 人、B 梯次約 35–40 人** 為舒適上限；超過需延長時間或增加梯次。

## 4. 第四場 A22 正式賽（建議賽制，待確認）

- **資格賽**（上午）：每組 4–5 條路線，輪轉制（每條 4 分鐘、休息 4 分鐘），計 Top / Zone / 嘗試次數。
- **決賽**（下午）：各組資格賽前 6 名，每組 3–4 條路線，隔離區＋觀線，輪流上場。
- 敘獎：各組前 2 名（亦可擴大至前 3 名，因為是正式賽）。
- 若決賽排下午，練習時段改為「非決賽選手練習區」。

### 系列賽總排名（選配）
- 四場各依名次給系列積分（第 1 名 100、第 2 名 80、第 3 名 65…），第四場 ×1.5。
- 報名四場套票選手才列入總排名，可增加套票誘因。

## 7. 設備清單（每場）
- 比賽 iPad：每面牆區 1 台（建議 4–6 台）＋備用 1 台，含支架、行動電源。
- 感應設備：見《網站規劃》第 5 節（iPad 無法直接讀 NFC，需外接讀卡機或改掃 QR）。
- 叫號／成績大螢幕：電視 1–2 台（接筆電或 Chromecast / Apple TV）。
- 網路：4G/5G 分享器 ×2（不要只靠場館 Wi-Fi）。
- 紙本備援記分表（系統故障時使用）。
